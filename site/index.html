◧实时预览

编辑 / 分栏 / 阅读三种模式，分栏宽度可拖动；渲染前转义 HTML，链接交给系统浏览器。

▤多标签 · 多窗口

一个窗口切多个文档，或每篇一个独立窗口。切换时未保存的正文、滚动位置、光标都跟着走。

☰左侧文件目录

列出当前文件夹的 Markdown / 文本文件，单击选中、双击打开，跟资源管理器一致。

⌗右侧章节大纲

按标题自动生成章节树，点一条跳转；随编辑实时更新，滚动时高亮当前章节。

⌕查找与高亮

Ctrl+F 打开查找条，命中标黄、当前标橙并自动滚到可视区。

⧉复制文件本身

右键「复制文件」＝ Win32 SetClipboardData(CF_HDROP)，剪贴板里是文件，能粘到资源管理器或微信。

↓拖进来就打开

把 .md 拖进窗口直接打开；把文件夹拖进来，左侧列出该目录。

◐深色 / 浅色

两套主题、字号缩放、面板宽度与开关状态全部记住，重启后原样恢复。

✓完整渲染

标题、粗体斜体删除线、行内代码、代码块、引用、嵌套列表、任务列表、表格（含对齐）、分割线、链接、图片。

安装版

Windows 10 / 11 · x64

装完 双击 .md 默认用它打开（.markdown / .mdown / .mkd / .mdwn 同理）， 开始菜单有快捷方式，可在「设置 → 应用」里正常卸载。

关于小银 Markdown

界面是自写的零依赖 Markdown 渲染引擎，桌面壳有两条：默认下载走 Tauri 2 + 系统 WebView2， 桌面能力由 Rust 直接调 Win32；仓库里还保留着 Electron 版。

✓隐私

不联网、不登录、不收集数据。唯一的网络行为是你点预览里的外部链接，交给系统浏览器打开。

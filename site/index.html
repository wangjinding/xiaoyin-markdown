功能
快捷键

该有的都有，不该有的一个没有

没有账号、没有云同步、没有遥测。打开就能写，关掉就结束。

◧实时预览

编辑 / 分栏 / 阅读三种模式，分栏宽度可拖动；渲染前转义 HTML，链接交给系统浏览器打开。

▤多标签 · 多窗口

「标签」模式一个窗口切多个文档，「独立窗口」模式每篇一个窗口。切换时正文、滚动位置、光标都跟着迁移，不会丢。

☰左侧文件目录

列出当前文件夹里的 Markdown / 文本文件。单击选中、双击打开，跟资源管理器一致；记住上次打开的文件夹。

⌗右侧章节大纲

按标题自动生成章节树，点一条跳转；随编辑实时更新，滚动时高亮当前章节。

⌕查找与高亮

Ctrl+F 打开查找条，正文里所有命中标黄、当前命中标橙并自动滚到可视区，编辑时实时恢复。

⧉复制文件本身

右键「复制文件」＝调用 Win32 SetClipboardData(CF_HDROP)，剪贴板里是文件，能直接粘到资源管理器或微信。

↓拖进来就打开

把 .md 文件拖进窗口直接打开；把文件夹拖进来，左侧列出该目录。

◐深色 / 浅色

两套主题、字号缩放、面板宽度与开关状态全部记住，重启后原样恢复。

✓完整渲染

标题、粗体斜体删除线、行内代码、代码块、引用、嵌套列表、任务列表、表格（含对齐）、分割线、链接、图片。

关于

小银 Markdown 是一个纯本地的 Windows 桌面编辑器，界面是同一套自写的零依赖 Markdown 渲染引擎，桌面壳有两条：

安装版（默认下载）走 Tauri 2 + 系统 WebView2，安装包只有 1.6 MB， 桌面能力（剪贴板文件、文件关联等）由 Rust 直接调 Win32； Electron 版仍保留在仓库里（src/main.js），体积大但自带运行时。

✓隐私

不联网、不登录、不收集数据。唯一的网络行为是你点击预览里的外部链接时，交给系统浏览器打开。
